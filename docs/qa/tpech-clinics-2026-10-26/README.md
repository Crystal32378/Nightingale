# 聯合醫院門診科別查詢（Tavily）驗證紀錄 — 2026-10-26

範圍：臺北市立聯合醫院。先選院區，再查詢該院區的門診科別；每個科別附官方掛號頁面與資料來源。中英文都可以查，畫面一律顯示官方中文名稱。不做自動掛號、不依症狀推薦科別、不代表院內位置。

## 資料怎麼來

| 步驟 | 內容 |
|---|---|
| 1 | 使用者打開「門診科別查詢」才開始查，沒打開就不呼叫 Tavily |
| 2 | 代理用 Tavily Extract 讀官方首頁 `https://webreg.tpech.gov.tw/`，取出 25 個院區／門診部和代碼（ZCode） |
| 3 | 選了院區，代理讀 `RegOnline1_1.aspx?ZCode=…`，取出科別名稱與科別代碼（DeptCode） |
| 4 | 科別名稱就是頁面上的連結文字，原字照登；掛號連結用院區代碼、科別代碼和名稱組回官方 `RegOnline1_2.aspx` |
| 5 | 同一頁一小時內重複查詢用快取，不再花 Tavily credit |

英文科別名稱是本站翻譯（`src/clinics/english.ts`），因為官方英文網站 `webreg.tpech.gov.tw/eng/` 回 404。翻譯旁邊一定附官方中文名稱。

## 限制

- 手機實機、正式部署環境還沒測。
- 英文翻譯表只收了 36 個常見科別名稱；其他科別（例如青少年親善門診、疫苗門診）只能用中文查，英文畫面也只顯示中文。
- 快取存在代理記憶體，重啟或多個執行個體各自重新抓。
- 名單照官方全部列出（含疫苗、自費特診），沒有替醫院篩選。
